# 기능 명세

이 문서는 코드에 구현된 사용자 기능을 화면과 업무 흐름 기준으로 정리한다. 기능 이름은 한국어 UI 문자열을 기준으로 한다.

## 계정 등록과 인증

- 사용자는 서버 주소를 입력해 계정을 추가한다. 주소는 앞뒤 공백과 마지막 `/`를 제거하고, 스킴이 없으면 `https://`를 붙인다.
- OAuth 등록 전 `/api/meta` POST가 성공하고 `name` 또는 `version`이 있으면 Misskey로, 그 외에는 Mastodon으로 간주한다.
- Mastodon은 앱 등록 API를 호출하고 `read write follow` 스코프로 OAuth Authorization Code 플로우를 사용한다.
- Misskey는 MiAuth 세션을 만들고 `read:account`, `read:notifications`, `read:notes`, `write:notes`, `write:drive`, `write:reactions`, `write:favorites`, `write:following`, `write:mutes`, `write:blocks` 권한을 요청한다.
- OAuth 진행 상태는 `sessionStorage`에 저장하며, 콜백 시 `state`와 Misskey `session`을 검증한다.
- Mastodon 앱 등록 정보는 같은 리다이렉트 URI에서 재사용할 수 있도록 세션 저장소에 캐시한다. Misskey는 매번 새 MiAuth 세션을 만든다.
- 콜백 후 토큰으로 계정을 검증하고 표시명, 핸들, 아바타, 계정 이모지를 갱신한다.
- 같은 플랫폼, 같은 인스턴스, 같은 핸들의 계정은 중복 등록하지 않고 기존 계정을 활성화한다.
- 설정 모달에서 등록 계정을 선택해 재인증하거나 삭제할 수 있다.
- 활성 계정은 별도로 저장하며, 앱 시작 시 저장된 계정이 있으면 검증 정보를 백그라운드로 새로고침한다.

## 계정 저장과 로컬 데이터

- 계정 목록과 토큰은 브라우저 `localStorage`에 저장한다.
- 마지막 사용 시각 이후 7일이 지나면 계정 목록과 마지막 사용 시각을 삭제하고 빈 계정 상태로 시작한다.
- 계정이 없으면 타임라인 영역은 표시하지 않고, 사이드바의 계정 추가 흐름을 중심으로 시작한다.
- `로컬 저장소 초기화`는 확인 후 `localStorage.clear()`를 실행하고 페이지를 새로고침한다.

## 타임라인 보드와 섹션

- 홈 화면은 왼쪽 사이드바와 오른쪽 멀티 컬럼 타임라인 보드로 구성된다.
- 각 섹션은 독립적으로 계정과 타임라인 종류를 가진다.
- 새 계정이 추가되면 해당 계정의 홈 타임라인 섹션을 자동으로 추가한다.
- 섹션은 왼쪽/오른쪽에 추가할 수 있고, 좌우로 이동할 수 있으며, 2개 이상일 때 삭제할 수 있다.
- 섹션 설정은 프로필 이미지 표시, 커스텀 이모지 표시, 리액션 표시, 섹션 폭을 개별로 조정한다.
- 섹션 폭은 `small`, `medium`, `large`이며 각각 대략 440/550/660px 기준 폭을 사용한다.
- 섹션 설정과 순서는 `localStorage`에 저장된다.
- 섹션 계정이 삭제되면 해당 섹션의 계정은 `null`로 바뀌고 타임라인 종류는 유효한 기본값으로 정규화된다.

## 지원 타임라인

- Mastodon: 홈, 로컬, 연합, 알림, 북마크를 지원한다.
- Misskey: 홈, 로컬, 소셜, 글로벌, 알림을 지원한다.
- 계정 플랫폼에서 지원하지 않는 타임라인은 홈으로 정규화한다.
- 일반 타임라인 메뉴에는 알림을 포함하지 않는다. 알림은 별도 버튼과 알림 컬럼/팝오버로 다룬다.
- 북마크 타임라인은 Mastodon 전용이며 스트리밍을 사용하지 않는다.

## 타임라인 로딩과 스트리밍

- 최초 로딩은 30개를 가져오고, 하단 근처까지 스크롤하면 20개씩 추가 로딩한다.
- 같은 ID의 글은 중복 추가하지 않는다.
- 스트리밍 업데이트는 같은 ID가 있으면 교체하고, 없으면 맨 위에 병합한다.
- 사용자가 컬럼 최상단에 있지 않으면 새 글은 즉시 삽입하지 않고 대기열에 쌓는다.
- 대기 중인 새 글이 있으면 `새 글 N개` 배너를 보여주고, 클릭 시 대기열을 반영하고 맨 위로 이동한다.
- 타임라인별 보존 정책:
  - 홈: 최대 400개, 300ms 배치 반영, 대기열 200개.
  - 로컬: 최대 600개, 400ms 배치 반영, 대기열 240개.
  - 연합/글로벌: 최대 800개, 500ms 배치 반영, 대기열 260개.
  - 소셜: 최대 600개, 400ms 배치 반영, 대기열 220개.
  - 알림: 최대 300개, 400ms 배치 반영, 대기열 120개.
  - 북마크: 최대 500개, 스트리밍 대기열 없음.
- 스트리밍 삭제 이벤트는 목록과 대기열에서 해당 글을 제거한다.

## 알림

- 각 섹션 헤더에는 알림 버튼이 있으며, 일반 타임라인을 보면서도 알림 스트리밍을 별도로 감지한다.
- 새 알림이 오면 섹션 배지가 최대 `99+`까지 증가한다.
- 알림 팝오버를 열면 배지를 초기화하고 알림 목록을 새로고침한다.
- 알림 팝오버도 무한 스크롤을 지원한다.
- 일반 타임라인 컬럼에서 알림이 오면 5초 간격으로 토스트를 보여주고, 토스트 액션으로 해당 컬럼으로 스크롤할 수 있다.
- 알림 타임라인 자체에서는 새 알림 토스트를 중복으로 띄우지 않는다.

## 글쓰기

- 글쓰기 패널은 계정 선택, 본문, 공개 범위, 콘텐츠 경고, 이미지 첨부, 이모지 팔레트, 전송 버튼으로 구성된다.
- 공개 범위는 전체 공개, 미등록, 팔로워, DM을 지원한다.
- 공개 범위는 계정별로 `localStorage`에 저장된다.
- 전체 공개를 선택하면 `전체 공개로 게시됩니다. 민감한 내용은 주의해주세요.` 경고를 보여준다.
- 콘텐츠 경고를 켜면 별도 입력란을 표시하고, 끄면 경고 텍스트를 비운다.
- 답글 작성 시 글쓰기 계정을 해당 컬럼 계정으로 바꾸고, 대상 계정 멘션을 본문에 자동으로 넣는다.
- 답글 대상에 콘텐츠 경고가 있으면 답글 입력도 같은 콘텐츠 경고로 시작한다.
- 글자 수는 인스턴스 정보에서 가져온 제한을 기준으로 표시한다.
- Mastodon 글자 수 계산은 URL을 23자로 계산한다. Misskey는 순수 텍스트 길이를 사용한다.
- 제한의 80% 이상은 경고 상태, 100% 이상은 제한 상태로 표시한다.
- 제한을 초과하면 전송하지 않고 토스트 오류를 보여준다.
- 이미지는 파일 선택 또는 텍스트 영역에 이미지 붙여넣기로 첨부한다.
- 첨부 이미지는 썸네일로 표시하고, 클릭하면 확대/축소, 드래그 이동, 삭제가 가능한 미리보기 모달을 연다.
- 전송 중에는 `게시 중...` 오버레이를 보여주고 입력을 비활성화한다.
- 전송 성공 시 본문과 첨부를 비우고, 작성된 글을 해당 계정의 타임라인 리스너에 브로드캐스트한다.

## 이모지 입력

- 커스텀 이모지는 계정 인스턴스별로 API에서 가져오며 메모리 캐시를 사용한다.
- 표준 유니코드 이모지는 `emoji-datasource`에서 Apple 이미지가 있는 항목을 기준으로 카테고리화한다.
- 카테고리 라벨은 한국어로 표시한다.
- 최근 사용 이모지는 인스턴스별로 최대 24개를 저장한다.
- 본문에서 `:query`를 입력하면 최대 5개의 이모지 추천을 보여준다.
- 이모지 검색은 shortcode에 대한 퍼지 매칭을 사용한다.
- 커스텀 이모지는 `\u200b:shortcode:\u200b`, 표준 이모지는 `\u200b이모지\u200b` 형태로 삽입한다.
- 이모지 패널과 리액션 패널은 최근 사용, 커스텀 카테고리, 표준 이모지 카테고리를 제공한다.

## 게시글 표시

- 일반 글, 부스트/리노트 글, 알림을 하나의 `Status` 모델로 렌더링한다.
- 부스트 글은 부스트한 사용자를 상단에 표시하고 실제 대상 글을 본문으로 표시한다.
- 답글은 멘션 대상 목록과 `에게 보낸 답글` 라벨을 표시한다.
- 알림은 알림 행위자를 상단에 표시하고, 알림 대상 글이 있으면 그 글을 본문으로 표시한다.
- 콘텐츠 경고가 있으면 기본적으로 본문을 숨기고 `내용보기`/`가리기` 버튼을 제공한다.
- Mastodon HTML 본문은 DOMPurify로 정화 후 렌더링한다.
- Misskey 일반 텍스트는 간단한 Markdown 렌더러로 변환하고 정화 후 렌더링한다.
- 커스텀 이모지 표시가 켜져 있으면 사용자 이름과 본문 shortcode를 이미지로 바꾼다.
- 멘션 링크는 프로필 모달로 열 수 있다. 자기 계정 멘션은 클릭을 막는다.
- 공개 범위 아이콘은 public, private, direct에 표시한다. unlisted는 별도 아이콘을 표시하지 않는다.
- 원본 글 URL이 없으면 활성 계정 호스트와 글 ID로 Misskey 노트 URL을 추정한다.

## 링크와 미디어

- Mastodon 카드 정보가 있으면 링크 미리보기 카드를 표시한다.
- Misskey에서 카드가 없고 본문에 URL이 있으면 production 환경에서 `/api/preview`를 호출해 링크 미리보기를 가져온다.
- GitHub Pages 호스트에서는 링크 미리보기 API를 사용하지 않는다.
- 이미지 첨부는 썸네일 버튼으로 표시하고, 원본 보기 모달은 좌우 이동, 마우스 휠 줌, 포인터 드래그를 지원한다.
- 이미지가 여러 장이면 이전/다음 버튼과 카운터를 표시한다.
- 비디오와 gifv는 `<video controls>`로 표시한다.
- 재생 중인 비디오가 화면 밖으로 나가면 하나의 플로팅 플레이어로 고정되며, 닫기와 크기 조절을 지원한다.
- 오디오는 `<audio controls>`로 표시한다.
- 알 수 없는 첨부 파일은 새 탭으로 여는 링크를 표시한다.

## 게시글 액션

- 답글, 좋아요, 부스트/리노트, 북마크/즐겨찾기, 리액션, 번역, 삭제, 원본 서버에서 보기를 지원한다.
- Mastodon은 좋아요와 북마크를 별도 액션으로 처리한다.
- Misskey는 즐겨찾기 API를 좋아요/북마크에 공통으로 사용하고, 리액션을 별도 지원한다.
- Misskey 게시글 메뉴를 열면 현재 즐겨찾기 상태를 `fetchNoteState`로 확인한다.
- 자기 글, 비공개 글, DM은 새 부스트가 비활성화된다.
- 삭제 버튼은 현재 활성 계정과 게시글 작성자가 같은 경우에만 표시한다.
- 삭제 전에는 확인 모달을 띄우고 게시글 미리보기를 보여준다.
- 번역은 게시글 메뉴에서 실행하며, 결과와 감지 언어/대상 언어/제공자 메타를 표시한다.
- 번역 결과는 다시 메뉴를 누르거나 결과 영역의 `번역 숨기기`로 닫을 수 있다.

## 리액션

- 리액션은 Misskey 계정에서만 사용할 수 있다.
- 이미 다른 리액션이 있으면 먼저 취소하라는 오류를 보여준다.
- 같은 리액션을 누르면 취소로 처리한다.
- 타임라인에서는 낙관적 업데이트로 리액션 카운트를 즉시 반영하고 실패하면 롤백한다.
- 서버 응답과 낙관적 상태의 리액션 서명이 다르면 서버 응답으로 교체한다.
- `L` 단축키는 Mastodon에서는 좋아요, Misskey에서는 기본 하트 리액션을 실행한다.

## 게시글 상세 모달

- 게시글 클릭 또는 Enter 단축키로 상세 모달을 연다.
- 상세 모달은 컬럼 계정으로 스레드 컨텍스트를 가져온다.
- Mastodon은 ancestors와 descendants를 사용한다.
- Misskey는 conversation을 시간순으로 정렬해 ancestors를 만들고, children API를 BFS로 최대 200개/깊이 6까지 탐색해 descendants를 만든다.
- 스레드 로딩 중 헤더에 스피너와 `스레드 불러오는 중`을 표시한다.
- 상세 모달 안의 스레드 항목은 리액션 액션을 비활성화한다.

## 프로필 모달

- 아바타나 계정 영역, 멘션 링크, `P` 단축키로 프로필 모달을 연다.
- 프로필은 헤더 이미지, 아바타, 이름, 핸들, 소개, 필드, 작성한 글을 보여준다.
- 프로필 API 실패 시 게시글에 들어있는 작성자 정보로 최소 프로필을 구성한다.
- 소개와 필드는 HTML, Markdown, 일반 텍스트를 감지해 각각 정화/렌더링한다.
- 작성한 글은 20개씩 가져오고, 모달 스크롤 하단 근처에서 추가 로딩한다.
- 프로필에서 다른 프로필을 열면 모달 스택에 새 프로필 모달을 쌓는다.
- 현재 계정이 아닌 대상에게 팔로우, 팔로우 요청 취소, 언팔로우, 뮤트/해제, 차단/해제를 수행할 수 있다.
- 잠긴 계정은 팔로우 요청 상태로 처리한다.
- 언팔로우는 별도 확인 팝업을 거친다.
- 팔로우/뮤트/차단은 낙관적 관계 업데이트 후 실패 시 이전 관계로 롤백한다.
- 원본 사이트에서 보기를 지원한다.

## 설정과 정보 페이지

- 설정 모달은 계정 관리, 테마, 색상 모드, 뽀모도로 표시 여부와 시간, 로컬 저장소 초기화를 제공한다.
- 테마는 기본, 크리스마스, 하늘핑크, 모노톤, 말차코어, 로얄퍼플, 여름해변을 지원한다.
- 색상 모드는 시스템, 라이트, 다크를 지원한다.
- 이용약관, 라이선스, 오픈소스 목록, 단축키는 해시 라우트와 모달 둘 다로 접근할 수 있다.
- 이용약관과 오픈소스 목록은 Markdown을 HTML로 렌더링하고 정화한다.
- 라이선스는 원문을 `<pre>`로 표시한다.

## 뽀모도로 타이머

- 설정에서 켜면 사이드바에 뽀모도로 타이머가 표시된다.
- 집중, 휴식, 긴 휴식 시간은 설정에서 분 단위로 조정한다.
- 4사이클 고정이며 세션은 집중/휴식이 번갈아 나오고 마지막은 긴 휴식이다.
- 현재 세션, 남은 시간, 실행 상태, 완료 세션, 투두 목록은 `localStorage`에 저장된다.
- 타이머 종료 시 Web Audio API로 짧은 알림음을 재생하고 패널이 깜빡인다.
- 집중 세션이 실행 중이면 타임라인 콘텐츠를 흐리게 처리하고 클릭을 막으며 집중 안내 메시지를 보여준다.
- 투두는 추가, 완료 토글, 삭제, 더블 클릭 편집, 드래그 순서 변경을 지원한다.
- 투두 목록에서 오른쪽 방향키를 누르면 같은 높이의 왼쪽 첫 타임라인 글을 선택할 수 있다.

## 모바일 동작

- 900px 이하 화면에서는 본문 UI 대신 모바일 안내 블로커를 표시한다.
- 모바일 헤더, 글쓰기 메뉴, 모바일 메뉴 컴포넌트가 구현되어 있지만 실제 앱은 멀티 컬럼 특성상 모바일 사용 불가 안내를 우선 표시한다.

## 토스트와 오버레이

- 토스트는 success, error, info 톤을 지원하며 기본 3초 후 사라진다.
- 토스트 액션 버튼을 optional로 제공할 수 있다.
- 모든 메뉴, 팝오버, 모달은 배경 틴트 오버레이를 동반하고 외부 클릭 또는 ESC 정책으로 닫힌다.
